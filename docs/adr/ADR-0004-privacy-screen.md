# ADR-0004: 隐私屏保持禁用（ER-701）

- 状态: 接受（v1 不提供隐私屏）
- 日期: 2026-11-22
- 关联: ER-701、PRD §5.2.6、能力台账 privacy_screen=disabled

## 背景

PRD 隐私屏语义是“本机物理显示不可见、远端采集继续”。旧实现把采集帧涂黑，方向相反：远端看不到但本机屏幕仍显示敏感内容，既不能满足隐私，又破坏远控。

真正实现需要平台级“仅本机显示不可见”：
- macOS：覆盖/调暗物理显示且不影响 CGDisplayStream 采集；
- Windows：DWM/显示器电源控制且采集仍可读；
- Linux：DRM/合成器配合。
当前无跨平台可靠 API，也未在真机验证。

## 决策

1. v1 不实现隐私屏；能力台账保持 disabled，UI 只读并说明原因。
2. 删除 er-capture/privacy 的“涂黑采集帧”实现，防止被误接入生产。
3. 只有在本机物理显示不可见且远端采集继续的端到端验证完成后，才可升级能力。
4. 不提供“假装隐私”的开关。

## 后果

- 用户无法启用隐私屏；需在产品文案明确。
- 不会出现“远端黑屏但本机仍暴露”的错误安全承诺。

## 验证

- 能力台账 privacy_screen disabled；发布/开发均不显示可操作开关（既有 capability 测试）。
- 代码扫描不得再出现采集帧涂黑路径。
