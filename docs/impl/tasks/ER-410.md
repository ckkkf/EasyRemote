# ER-410 生产迁移与 dev seed 拆分

## 目标与成熟度
生产 PG 启动只做迁移，不创建已知 root 管理员；开发/内存环境才 seed。成熟度：beta（PG+Redis 生产烟测在 ER-411/ER-903 扩展）。

## 需求与字段映射
- seedDevAdminIfNotProduction(ctx, st)：生产直接返回，不写 admin。
- NewPostgres / NewPostgresWithRedis 调用 helper；NewDev 继续 SeedDevAdmin。
- SeedDevAdmin 自身仍拒绝生产（双保险）。

## 能力链
- cmd/stack PG 分支 → NewPostgres* → migrate → seed helper
- tests：内存 seed 分支 + 真实 Postgres 生产启动
- runbook：生产开户独立流程

## 当前证据
- A-07：NewPostgres/WithRedis 在生产调用 SeedDevAdmin，而 SeedDevAdmin 拒绝生产 → 启动失败。
- 无生产 PG 启动测试。

## 设计与不变量
- 生产启动绝不创建 root/dev-pass/固定 TOTP。
- 开发内存/PG 环境自动 seed，便于本地联调。
- 迁移与 seed 分离：迁移始终执行，seed 只在非生产。
- 测试使用真实 Postgres 容器验证迁移与无 admin。
