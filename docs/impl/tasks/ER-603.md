# ER-603 真实会话质量指标

## 目标与成熟度
控制器上报真实解码 FPS/码率/丢包/解码耗时；质量抽屉展示数据面指标并标注来源，去掉固定“已授权/未接入”。成熟度：beta（后台质量统计未接同一数据源）。

## 需求与字段映射
- CtrlStats：decode_fps、decode_ms、dropped_frames、bitrate_kbps、loss_pct。
- 统计窗口：1 秒；media_bytes 累计接收字节；relay.link_stats(1000).loss_pct。
- er_ctrl_info JSON 增加 bitrate_kbps/loss_pct。
- Dart SessionVideo：bitrateKbps/lossPct/presentFps/nativeFps/decodeMs。
- 质量抽屉：FPS=present/native，码率=最近 1 秒，丢包=数据面优先，否则网关 ping；解码耗时真实值。
- 文案说明数据面 vs 网关采样的区别。

## 能力链
- ctrl_session → CtrlStats → FFI → SessionVideo → 质量抽屉
- tests：FpsCounter / keyframe 等既有；UI 编译

## 当前证据
- A-12：FPS/码率破折号、链路固定“已授权”、延迟/丢包来自 gateway ping。
- 无数据面码率/丢包统计。

## 设计与不变量
- 指标必须来自真实执行点，不用 UI 计时器/健康检查代替。
- 数据面不可用时明确回退到网关探测并标注。
- 呈现 FPS 与 native FPS 分开显示，不混用。
- 无 telemetry 时不显示假数字。
