# ER-112 presence 租约：注册/心跳/断开/TTL

## 目标与成熟度
把在线状态从“绑定表布尔值”改成“信令连接租约”：注册写 TTL、心跳续租、断开撤销、实例崩溃靠 TTL 过期；设备在线视图读取同一权威来源。成熟度：beta。

## 需求与字段映射
- 租约：Bus.SetOnline(deviceID, token, presenceTTL=5min)。
- 心跳：客户端 TypeHeartbeat(0x7F) → Hub.Touch(deviceID, conn) → 续租同一 token。
- 断开：Hub.Unregister(self) → ClearOnline(仅当 token 匹配)。
- 过期：无心跳 → Bus.IsOnline=false（TTL）。
- 设备视图：/v1/devices 在注入 Presence 时以 Presence 为准。

## 能力链
- rendezvous/stack WS 循环 → Hub.Touch
- Hub.Register/Unregister → Bus
- gateway /v1/devices → Presence.Online
- tests：ttlBus 可控时钟 + fake presence

## 当前证据
- A-08：注册只写一次 TTL，心跳未续租；绑定即 online=true；设备列表读 store 旧布尔值。
- Rust 客户端每 20s 发 TypeHeartbeat，服务端 switch 忽略。

## 设计与不变量
- 只有当前连接（conn 身份相等）能续租；旧连接不能把新连接标记续命。
- 断开必须同步 ClearOnline(token)；token 带 instance#generation，防旧连接误删。
- 崩溃场景不主动清理，靠 TTL 过期；测试用可控时钟验证。
- Presence 未注入（内存开发）时设备列表回落 store；生产必须注入。
