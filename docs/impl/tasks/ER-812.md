# ER-812 后台中断等待领域结果

## 目标与成熟度
中断返回 closed/propagated/audited/warning；传播失败为 partial 而不是完全成功；审计记录实际结果；UI 显示部分失败/超时，不承诺未发生事件。成熟度：beta。

## 需求与字段映射
- contract KillSessionResult：closed/propagated/audited/warning?；ADM-08 response。
- adminapi.KillSession 返回结果：先 Kill → 传播 → 再审计；warning 记录失败原因。
- adminhttp 返回 KillSessionResult。
- web-admin：10s AbortController 超时；partial 展示 warning；成功文案注明传播与审计已确认；修改“立即生效”文案。

## 能力链
- UI kill → adminhttp → session.Kill → closer.NotifySessionClosed → audit → result
- tests：TestKillSessionReportsPartialPropagation；既有 kill 审计测试
