# ER-013 统一身份凭证语义与文件子资源登记

## 目标与成熟度
contract-first 修正只读接口的方法与鉴权语义（bearer/device 各归其位），把文件子资源（下载/删除/取票）登记进契约并纳入 method guard；用跨账号/跨设备负向测试证明越权被拒绝。成熟度：beta。

## 需求与字段映射
| 端点 | method | auth | 校验规则 |
|---|---|---|---|
| GW-08 /v1/connect/status | GET | bearer | 账号必须拥有会话一方 |
| GW-10 /v1/connect/keys | GET | bearer | 账号必须拥有会话一方 |
| GW-07 consent | POST | device | 必须是目标设备本机凭证 |
| GW-09 identity | POST | device | 设备属于账号 + 本机设备凭证 |
| GW-11 relay/ticket | POST | device | 会话双方任一设备凭证 |
| GW-22 DELETE /v1/files/ | DELETE | bearer | 文件属于该账号 |
| GW-23 POST /v1/files/（ticket） | POST | bearer | 文件属于该账号 + 设备凭证 |

- 契约：GW-08/10/19 已改 GET（ER-012）；本卡新增 GW-22/23 与 FileDeletedResult/FileTicketResult。
- 响应字段沿用 ER-011 生成类型。

## 能力链
- 契约 → 生成物 → RouteSpec → MethodGuard（含 / 前缀）
- gateway handler 鉴权：account + ownsDevice / requireDevice
- 测试：gateway 跨账号负向 + 正向；后台/路由检查不变

## 当前证据
- status 原实现只看 device 凭证，契约写 bearer；无关账号若持有任意设备凭证语义不清。
- 文件下载/删除/取票未进契约；MethodGuard 只覆盖精确路径。
- 无跨账号访问负向测试（A-17）。

## 设计与不变量
- 只读状态/公钥：账号级 bearer，再校验 ownsDevice(controller|target)，禁止仅凭“知道 session_id”读取。
- 写/设备动作：device 凭证必须是目标设备或会话双方之一。
- 文件子资源用集合前缀 /v1/files/ 登记多方法；MethodGuard 对前缀做 method 白名单，具体子资源仍由 handler 校验。
- 跨账号一律 ADMIN_FORBIDDEN；文件不存在与无权限都不得泄露内容（403/404 均可，测试接受两者之一）。
