# ER-700 被控端本地常驻控制条

## 目标与成熟度
会话中在被控端本地显示常驻控制条（会话号、仅本机可断开、一键断开），远端不能隐藏/关闭。成熟度：beta（本机 UI + 关闭 API；端到端“远端无法隐藏”无自动化）。

## 需求与字段映射
- LocalControlBar：sessionId、onDisconnect；key local-control-bar/local-control-disconnect；无关闭按钮。
- 设备页：HostStatus.hasSession 时置顶显示；断开调用 HostService.closeSession。
- Rust：Gateway.close_session → POST /v1/sessions/close；TargetAgent.close_session。
- FFI：er_host_close_session(host_id, session_id)。
- Dart HostService.closeSession。

## 能力链
- DeviceListPage 轮询 HostStatus → LocalControlBar
- 点击 → HostService.closeSession → FFI → /v1/sessions/close（服务端关闭+传播）
- tests：widget 控制条/无关闭入口/断开回调

## 当前证据
- 被控端只有设置开关，无会话中常驻控制条；远端无法被本机一键断开。
- 无关闭会话 FFI。

## 设计与不变量
- 控制条只在被控端本地渲染，远端输入不能影响。
- 不提供“隐藏/关闭控制条”入口；仅可断开。
- 断开走服务端 close（写 reason/传播），不是只停本地流。
- 失败时保持控制条并显示错误，不假装已断开。
