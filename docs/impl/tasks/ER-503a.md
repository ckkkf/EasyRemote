# ER-503a 浏览器 WebTransport 显式降级

## 目标与成熟度
在 wtransport/h3 适配未实现前，明确 v1 浏览器不做 WebTransport/远程控制；Web stub 必须禁用视频/被控并提示桌面端，不伪装能力。成熟度：ADR（显式降级）。

## 需求与字段映射
- ADR-0002：浏览器只保留 HTTP + WS 控制面；不建立 WebTransport 数据面。
- session_video_stub：attach 不建立会话，error 提示桌面端。
- HostService stub：supported=false。
- 发布能力门控隐藏 experimental（ER-000 已有）。

## 能力链
- Flutter Web stub（video/host）
- 能力台账/发布隐藏
- tests：Web stub 行为

## 当前证据
- ER-503 只有原生 QUIC；浏览器 WebTransport 未实现，但无明确降级声明/测试。

## 设计与不变量
- 不得宣称浏览器 WebTransport/实时画面。
- Web 端视频/输入入口明确禁用，不显示空壳。
- 后端 webtransport_url 字段保留但不代表能力可用。
- 未来接入 wtransport 必须新 ADR + 浏览器测试。
