# ER-710a 剪贴板接入会话 data stream（opt-in）

## 目标与成熟度
剪贴板消息进入真实会话中继通道：编码/解码、1MB 上限、开关门控；通过 ER_CLIPBOARD_SYNC=1 显式启用，默认关闭。成熟度：experimental（无 UI，能力仍 disabled）。

## 需求与字段映射
- er-channels：MSG_CLIP=0x30，encode_clip/decode_clip，MAX_CLIP_BYTES=1MB。
- ctrl_session/host_stream：开启时 1s 轮询本机剪贴板并发送；收到 MSG_CLIP 应用远端。
- 关闭时完全零读写（ClipboardService 不创建）。
- 复用 ClipboardSync：白名单/大小/回声抑制。

## 能力链
- OS 剪贴板 → ClipboardService → MSG_CLIP → RelayClient → 对端 ClipboardService → OS
- tests：clip_roundtrip / bad kind / oversize；disabled 零读写（既有）

## 验收断言 → 测试 → 结果
| 断言 | 测试 | 结果 |
|---|---|---|
| 编码/解码往返 | clip_roundtrip | PASS |
| 非法 kind/截断拒绝 | clip_rejects_bad_kind_and_truncation | PASS |
| 超 1MB 拒绝 | clip_rejects_oversize | PASS |
| 默认关闭零副作用 | env 未设置不创建 service | PASS（代码） |
