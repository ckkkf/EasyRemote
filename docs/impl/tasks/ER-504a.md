# ER-504a Relay 重启恢复（注册层）

## 目标与成熟度
中继重启/短暂不可达时，客户端按退避策略重新注册并恢复；用同一端口重启 + ACK 测试证明。成熟度：experimental（注册层恢复完成；会话级自动重连未实现）。

## 需求与字段映射
- register_with_retry：退避 + 总 deadline；每次 register 等 ACK。
- BackoffPolicy::fast 测试策略（10ms 起，最多 8 次）。
- 测试：先占用端口再释放，300ms 后同端口重启并 ACK。

## 能力链
- RelayClient.register_with_retry → BackoffPolicy
- mock relay 重启
- tests：register_recovers_after_relay_restart

## 当前证据
- ER-501 注册有 ACK/重试，但没有“中继重启后恢复”的测试。
- 会话中自动重连不存在。

## 设计与不变量
- 重试必须有总 deadline 和退避上限；不得无限忙等。
- 恢复以收到 ACK 为准，不以发送成功。
- 测试固定端口重启，禁止依赖外部进程。
