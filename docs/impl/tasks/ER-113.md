# ER-113 WebSocket Origin allowlist / 读上限 / 认证 deadline

## 目标与成熟度
信令 WebSocket 不再接受任意 Origin：按 ER_ALLOWED_ORIGINS 精确 allowlist（未配置时仅 localhost/127.0.0.1/::1），空 Origin 仅给原生客户端；单条消息上限 64KB；未在 5s 内 HELLO 认证的连接必须断开。成熟度：beta。

## 需求与字段映射
- Origin：精确 scheme+host+port；空 Origin 允许（Rust/原生不发 Origin）。
- 消息上限：64KB（signal.MaxWSMessageBytes）。
- 认证 deadline：signal.WSAuthTimeoutFromEnv，默认 5s，测试可用 ER_WS_AUTH_TIMEOUT 覆盖。
- 环境变量：ER_ALLOWED_ORIGINS（逗号分隔）。

## 能力链
- signal.WSUpgrader/OriginAllowed/WSAuthTimeoutFromEnv
- stack.BuildRendezvousWithHub 与 cmd/rendezvous 共用
- 测试：httptest + gorilla 客户端三条负向 + 既有正向

## 当前证据
- A-24：两处 CheckOrigin 恒 true；stack 侧无 SetReadLimit；认证只受每轮 60s 读超时约束。

## 设计与不变量
- 绝不 CheckOrigin=true；未配置也不等于全放行。
- 升级失败记录 remote/path/err（ER-110 已加日志）。
- 认证 deadline 从连接建立开始计算，不能靠反复发畸形帧续命。
- 超限消息由 SetReadLimit 关闭连接（1009）。
- 原生客户端无 Origin 时不受 allowlist 影响；浏览器跨站默认被拒。
