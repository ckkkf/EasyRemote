# ER-601a 视频纹理零拷贝 Spike/ADR

## 目标与成熟度
确定 Flutter 外部纹理路线，明确 native texture（A）与真正零拷贝（B）的边界；在实现前不宣称零拷贝。成熟度：ADR（未实现）。

## 需求与字段映射
- 现状：FFI RGBA → Dart buffer → decodeImageFromPixels → ui.Image。
- 候选：macOS FlutterTexture+CVPixelBuffer；IOSurface/Metal；D3D11；DMA-BUF。
- 决策：先做 native texture（A），再评估真正零拷贝（B）。

## 能力链
- ADR-0003
- 后续：Swift/Windows 插件、FFI 写 CVPixelBuffer、Dart Texture widget
- 验收：无 Dart 每帧解码；present FPS 与 native 差值≤10%

## 当前证据
- ER-601 已去 12fps 限帧并暴露 native FPS，但仍有 RGBA 拷贝/Dart 解码。
- 无纹理插件/平台通道。

## 设计与不变量
- A 方案仍有一次拷贝，不得宣称零拷贝。
- 失败必须回退现有路径并提示。
- 平台实现必须处理纹理生命周期/线程安全。
