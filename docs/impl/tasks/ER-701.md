# ER-701 隐私屏语义修正（禁用）

## 目标与成熟度
按 PRD“本机物理显示不可见、远端采集继续”评估隐私屏；当前无可靠跨平台实现，保持 disabled，删除“涂黑采集帧”的错误路径。成熟度：disabled（ADR）。

## 需求与字段映射
- 能力台账 privacy_screen=disabled。
- 禁止采集帧涂黑冒充隐私屏。
- 仅在本机显示不可见且远端采集继续的端到端验证后才可升级。

## 能力链

- 能力测试保证不可用

- 无平台级本机显示隐藏实现。

- 能力台账/UI 保持 disabled。
