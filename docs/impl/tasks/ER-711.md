# ER-711 文件传输（能力禁用，核心模块保留）

## 目标与成熟度
文件分块/校验/续传核心存在，但未接会话 data stream；为避免“网关存储冒充点对点”，file_transfer 能力降为 disabled 并隐藏入口。成熟度：disabled。

## 需求与字段映射
- er-channels FileSender/FileReceiver（块哈希/整文件哈希/续传）。
- 能力台账 file_transfer=disabled。
- shell 不渲染文件入口。

## 能力链

- 缺口：数据通道/流控/暂停恢复/UI
- tests：capability disabled；既有文件模块测试
