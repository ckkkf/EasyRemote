# ER-504 弱网注入：5% 丢包/抖动/乱序下的会话

## 目标与成熟度
E2E 服务自动启动 lossyproxy，在 5% 丢包 + 2ms 抖动 + 2% 乱序下验证注册/握手/加密/解码仍完成。成熟度：experimental（基本弱网通过；断网/Relay 重启/重连阈值未覆盖）。

## 需求与字段映射
- lossyproxy：-loss 0.05 -delay 2ms -jitter 2ms -reorder 0.02 -seed 7。
- E2eServices：新增 lossyRelayAddr；构建/启动/等待日志/停止；外部服务模式退化为直连。
- 测试：lossy_e2e_test。

## 能力链
- E2eServices → lossyproxy → relay → stack
- ErSessionRunner 经弱网中继建立会话
- tests：握手/keys/解码；link 可观测

## 当前证据
- 无弱网注入；现有 E2E 只走直连中继。
- 无断网/Relay 重启/重连阈值验证。

## 设计与不变量
- 注入参数固定种子，可复现。
- 不用固定 sleep 等就绪：读 lossyproxy 日志。
- 外部服务模式不注入代理，明确退化。
- 失败必须暴露日志，不 skip。
