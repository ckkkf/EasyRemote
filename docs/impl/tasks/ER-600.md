# ER-600 Host 采集/硬编能力矩阵与降档

## 目标与成熟度
探测本机编码能力（硬件/软件），按实测能力夹取分辨率/帧率/码率，能力不足明确降档，不宣称 1080p60。成熟度：beta（软件路径降档；硬件矩阵仅 Windows NVENC 探测）。

## 需求与字段映射
- EncoderCapability：kind、max_width/height、max_bitrate_kbps、software_1080p_fps。
- ResolvedEncodeConfig：config、downgraded、reason。
- host_capability：Windows NVENC 可用→硬件；否则软件。
- resolve_config：分辨率夹取、码率上限、按像素面积计算软件 fps；gop<=fps。
- host_stream/pair 使用解析后的配置；降档写入 last_error/日志。

## 能力链
- er-codec capability/resolve
- er-client host_stream/pair
- example media_capability 基准
- tests：4 条能力矩阵

## 当前证据
- A-11：软件编码 1080p60 请求无降档；本机实测 14.9fps。
- 无能力矩阵/降档原因。

## 设计与不变量
- 实测优先：软件 1080p 上限 15fps（留余量），720p 30，低分辨率 60。
- 4K 请求在软件能力下夹到 1080p，码率≤8000。
- 硬件能力 1080p60 保持，不无故降档。
- 降档必须可观测（reason/last_error），不得静默。
