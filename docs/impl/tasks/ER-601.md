# ER-601 控制器解码统计与去除人为限帧（部分）

## 目标与成熟度
移除 12fps 人为限帧；用真实解码窗口统计 FPS/耗时/丢帧，供 UI 与 native 对照。成熟度：experimental（零拷贝 texture 未实现，仍有每帧 RGBA 拷贝与 Dart 解码）。

## 需求与字段映射
- CtrlStats：frames、decode_fps、decode_ms、dropped_frames。
- FpsCounter：1 秒窗口，可注入时间测试。
- 解码循环：不再按 80ms 跳过帧；每帧解码尝试，失败计 dropped。
- er_ctrl_info JSON：fps/decode_ms/dropped。
- Dart SessionVideo：nativeFps/decodeMs/droppedFrames。

## 能力链
- ctrl_session run_loop → FpsCounter → CtrlStats
- er-ffi er_ctrl_info → SessionVideo
- tests：fps_counter_reports_window_rate

## 当前证据
- A-11：主动 12fps 限速；无真实 FPS/解码耗时统计；仍 RGBA 拷贝 + Dart decodeImageFromPixels。
- 无 native/present FPS 对照。

## 设计与不变量
- 不人为限帧；性能由真实解码能力决定。
- FPS 必须来自实际解码点（窗口计数），不是 UI 轮询次数。
- 解码失败计数 dropped，不静默。
- 未实现零拷贝前不得宣称“零拷贝/纹理”。
