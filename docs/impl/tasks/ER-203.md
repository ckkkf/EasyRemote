# ER-203 会话领域事件 + outbox + 审计

## 目标与成熟度
每次会话状态迁移在 CAS 同事务内写入 outbox 事件（session_id/from/to/old/new/reason/trace/version/at），并提供幂等消费与失败重试的分发器。成熟度：beta（事件落库 + 分发器；生产消费者进程未接线）。

## 需求与字段映射
- store.SessionEvent：ID、SessionID、FromDevice、ToDevice、OldState、NewState、Reason、TraceID、Version、At、Delivered、Attempts、LastError。
- 唯一键 (session_id, version)：重复写入忽略，保证幂等。
- trace：context 携带 trace_id（httpx.Middleware 注入），领域层从 context 读取。
- Store：UpdateSessionCASWithEvent / ListSessionEvents / MarkSessionEventDelivered / MarkSessionEventFailed。

## 能力链
- httpx.Middleware → trace.With
- session.applyTransition → CASWithEvent（Memory 锁内 / PG 事务）
- session.Dispatcher → handler(幂等) → delivered / attempts
- tests：事件字段、只投一次、失败重试

## 当前证据
- 迁移直接 UpdateSession，无事件/outbox；审计只存在于后台操作。
- 无 trace 传递到领域层。

## 设计与不变量
- 状态与事件同事务：CAS 失败 → 不写事件；事件冲突 → 忽略（同一 version 只一条）。
- 事件只在 changed=true 时写；幂等 no-op 不产生事件。
- 消费者必须按 event ID 幂等；分发器只标记 delivered 后不再返回该事件。
- 失败保留事件、attempts+1、记录 last_error，下轮重试。
- trace_id 来自请求上下文；缺失时为空但不阻塞迁移。
