## 设计与不变量
- 步骤清单一处定义（`STEPS`），gate、自测、CI 对照测试都读它；不得在 CI 另写一套命令。
- 每步记录 stack、退出码、耗时；最终汇总按 stack 打印 PASS/FAIL；任一步失败 → 退出码非 0。
- `--report` 只报告不判红（不得作为完成证明）；`--update-baseline` 只更新禁止模式基线。
- `flutter analyze` 按 AGENTS 9.4：error/warning 必须为 0；info 计入存量债务（单独卡收敛），闸门打印数量。
- `flutter format` 使用官方格式器；格式化是一次性机械改动，不夹带逻辑变化。
- Rust clippy 严格 `-D warnings`；存量 lint 债务单独建候选卡（ER-001a），不在本卡顺手改业务代码。
