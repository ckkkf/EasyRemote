# ER-500 WebTransport Spike/ADR

## 目标与成熟度
用可复现基准比较 WebTransport 方案，决定原生/浏览器传输路线；记录 PRD 指标达成或退路。成熟度：ADR（后续实现 ER-501/503）。

## 需求与字段映射
- protocol.md 通道语义：媒体 datagram、控制/心跳可靠流、文件可靠流控。
- 指标：开销 <3%、延迟增量 <2ms；达不到必须记录退路。
- 证据：可复现示例 + 原始输出 + ADR。

## 能力链
- er-transport raw QUIC（已有）
- examples/transport_spike.rs（握手/吞吐/RTT）
- ADR 决策：原生 raw QUIC；浏览器 WebTransport 适配延后

## 当前证据
- A-09：裸 UDP 自定义分片，无 P2P/ICE；控制不可靠。
- 无 WebTransport 选型/基准。

## 设计与不变量
- 基准必须可复现（固定帧数/大小/命令）。
- 回环结果只作下限，不宣称生产达标。
- 不因 Spike 改生产传输；决策写入 ADR。
