# ER-402 FFI 所有权与 UI 阻塞

## 目标与成熟度
修复画面/被控 FFI 的 native 字符串泄漏；阻塞的会话 attach 移到后台 isolate，UI 事件循环不被握手卡住；补事件循环不被阻塞测试。成熟度：beta（被控 prepare/start 仍同步，长时 ASAN 归 ER-900）。

## 需求与字段映射
- SessionVideo.attach：6 个 native 字符串成对分配/释放；attach 在 Isolate.run 执行。
- SessionVideo.poll/send/close：session id native 字符串分配后立即释放。
- HostService.prepare/ensurePassword/start/status/stop：所有 toNativeUtf8 成对 free。
- attachRunner 测试注入点（io/stub 同步存在）。

## 能力链
- session_page → SessionVideo.attach（await，后台 isolate）→ FFI
- poll 定时拉帧 → decodeImageFromPixels
- HostService FFI → 页面
- tests：attach 未完成时 Timer 仍 tick；E2E 回归

## 当前证据
- SessionVideo.attach 同步执行且 6 个字符串未释放；poll/send/close 每次泄漏。
- HostService prepare/ensurePassword/start/status/stop 的输入字符串未释放。
- UI 切换会话时 attach 阻塞主 isolate。

## 设计与不变量
- 每个 toNativeUtf8 必须在 finally 中 calloc.free；返回串由 er_free_string 释放。
- attach 在后台 isolate；返回后主 isolate 重新打开库句柄供 poll/send。
- attach 失败记录 error，不抛到 UI；close 必须释放 image 与 session。
- 测试通过 attachRunner 注入 pending future，验证心跳继续。
