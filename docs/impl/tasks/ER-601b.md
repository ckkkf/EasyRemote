# ER-601b macOS FlutterTexture 原生纹理（未验证）

## 目标与成熟度
在 macOS 用 FlutterTexture + CVPixelBuffer 呈现 native 帧，移除 Dart decodeImageFromPixels/每帧 ui.Image；平台不支持时回退 RGBA。成熟度：experimental（代码完成，无法在本机编译验证：Xcode 未安装）。

## 需求与字段映射
- Rust FFI er_ctrl_frame_bgra：RGBA→BGRA 写入调用方缓冲。
- Swift VideoTexturePlugin：method channel easyremote/video_texture；create(session_id,width,height)/dispose(texture_id)；60Hz Timer 调 FFI 并 textureFrameAvailable。
- Dart VideoTextureBridge：MissingPlugin/PlatformException → null。
- SessionVideo：textureId/attachTexture；close 释放纹理。
- SessionPage：有 textureId 用 Texture，否则 RawImage 轮询回退。

## 能力链
- Swift plugin → dlopen liber_ffi → er_ctrl_frame_bgra
- Flutter Texture widget
- tests：TestTextureBridgeFallsBackWithoutPlugin；present FPS 计数

## 当前证据
- ER-601 仍 RGBA→Dart decode；无纹理通道。
- 本机无 Xcode，无法验证 Swift 编译/运行。

## 设计与不变量
- 平台插件不可用时必须回退 RawImage，不空白/不崩溃。
- 纹理路径仍有一次 native 拷贝，禁止宣称零拷贝。
- 纹理生命周期：close/dispose 必须 unregister；Timer 必须 invalidate。
- FFI 失败返回 0/负值，不通知新帧。
