# ER-810 后台真实身份/角色/权限

## 目标与成熟度
登录响应返回真实 username/role/permissions；前端不再硬编码 root/超级管理员；只读角色隐藏写操作与配置导航。成熟度：beta（登出撤销/平台存储仍 ER-811）。

## 需求与字段映射
- contract AdminSession：permissions list<string>。
- adminapi.Permissions(role)：白名单动作排序输出。
- adminhttp login 返回 Permissions。
- web-admin：AdminIdentity 存储（localStorage）、PermissionContext、useCan；侧栏显示真实用户名/角色；config 导航按 config.read 过滤；只读隐藏封禁/中断/配置保存与输入。

## 能力链
- adminapi permission → login response → web identity → UI gating
- tests：Permissions readonly/super
