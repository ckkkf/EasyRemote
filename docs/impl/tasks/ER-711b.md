# ER-711b 文件流接入 ctrl/host（opt-in）

## 目标与成熟度
通过环境变量显式启用文件传输：主控读取 ER_FILE_SEND_PATH，发送 meta + 单未 ACK 块；被控 ER_FILE_RECV_DIR 存在时接收、逐块 ACK、完成后校验并落盘。成熟度：experimental（无 UI）。

## 需求与字段映射
- ctrl_session：ER_FILE_SEND_PATH → StreamSender；收 MSG_FILE_ACK → ack；每轮 next_chunk。
- host_stream：ER_FILE_RECV_DIR → StreamReceiver；meta/chunk 处理，ACK，missing 空后 finish 写文件。
- 默认未设置环境变量时零行为。
