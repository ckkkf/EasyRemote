# ER-711c 文件最后块先落盘后 ACK

## 目标与成熟度
修正文件接收顺序：最后一块先 finish 校验 + 写盘成功，才发送 ACK；失败不 ACK 并记录错误，避免发送端误判完成。成熟度：experimental。

## 需求与字段映射
- host_stream：complete → 取 name → file_rx.take() → finish → fs::write；成功才 ack，失败写 last_error。
- 非最后块保持立即 ACK。
