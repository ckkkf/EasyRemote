# ER-502b 候选交换与 P2P 链路切换（会话编排）

## 目标与成熟度
RelayClient 在注册后交换候选、并行打洞、两阶段 ready，双方成功才切 P2P；否则保持 Relay。pair 会话上报 link 字段。成熟度：experimental（pair/会话编排完成；生产 host/ctrl 独立进程未接线）。

## 需求与字段映射
- RelayClient：prepare_p2p/await_candidates/punch/send_ready/await_ready/activate_p2p/link_kind。
- 候选消息 ERLINK1；ready 消息 ERLINK2。
- PairReport.link（p2p/relay）→ FFI JSON link。
- 发送：P2P 成功走 p2p socket；失败立即回退 Relay。
- 接收：P2P 优先 1ms poll，再 Relay。

## 能力链
- pair::run_pair 注册后 exchange → 并行 punch → ready → activate
- RelayClient send/recv 链路切换
- tests：候选编解码、链路激活、session E2E 断言 link=p2p

## 当前证据
- ER-502/502a 只有模块与编码，pair 未使用；无 link 字段。

## 设计与不变量
- 双方都成功才切 P2P；任一方失败双方保持 Relay。
- P2P 发送失败立即回退 Relay，不静默丢包。
- 握手仍在同一 RelayClient 上完成；加密层不变。
- link 必须可观测（PairReport/FFI）。
