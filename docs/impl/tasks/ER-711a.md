# ER-711a 文件会话流协议（部分）

## 目标与成熟度
定义文件会话消息与背压状态机：meta/chunk/ack、块哈希、单未 ACK 块流控、transfer_id 校验；尚未接 UI/FFI 入口。成熟度：experimental（核心）。

## 需求与字段映射
- MSG_FILE_META 0x40：id/total/name/hash。
- MSG_FILE_CHUNK 0x41：id/index/len/data/hash。
- MSG_FILE_ACK 0x42：id/index。
- StreamSender：未 ACK 不得发下一块；done。
- StreamReceiver：meta 建 FileReceiver；chunk 校验哈希；finish 整文件哈希。

## 验收断言 → 测试 → 结果
| 断言 | 测试 | 结果 |
|---|---|---|
| 全量传输 + ACK 背压 | full_transfer_with_ack_backpressure | PASS |
| 未 ACK 不发下一块 | no_second_chunk_until_ack | PASS |
| 块损坏拒绝 | corrupt_chunk_rejected | PASS |
| transfer_id 不符拒绝 | wrong_transfer_id_rejected | PASS |
