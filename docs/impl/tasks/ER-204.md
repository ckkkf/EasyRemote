# ER-204 Request 过期收口与并发首次唯一

## 目标与成熟度
Request 只复用未过期的 requested/authorized 或 active；关闭/超时/授权窗口过期的旧会话必须收口后新建；并发首次请求只能产生一个未关闭会话。成熟度：beta。

## 需求与字段映射
- requested 复用条件：now - started_at <= ConsentTimeout(30s)；超时 → close(request_expired)。
- authorized 复用条件：auth_expire_at 未过期；过期 → close(auth_window_exceeded)。
- active：直接复用。
- Store.CreateSessionExclusive：同一对设备最多一个 state != closed；Memory 扫描 + PG advisory lock。

## 能力链
- session.Request → 过期收口（Apply close）→ CreateSessionExclusive
- PG：pg_advisory_xact_lock(pair) + SELECT live + INSERT
- partial unique index sessions_live_pair_idx
- tests：closed/expired/并发

## 当前证据
- Request 无过期判断，超时 requested 会被复用；关闭会话不会被列表过滤前判断状态，但旧实现会复用 active/requested。
- 并发首次请求会各建一条。

## 设计与不变量
- 旧会话不可复活：closed 永不返回；超时 requested/authorized 先闭再建。
- 收口失败（并发已关闭）不阻塞新请求。
- 同一对设备最多一个未关闭会话（内存 + PG 双层）。
- 新会话仍写 requested，后续 ready 才 active（ER-201）。
