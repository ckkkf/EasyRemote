# ER-800 后台在线/会话计数接入权威 presence

## 目标与成熟度
后台概览的设备在线数与设备列表统一读信令 presence，而不是设备表历史布尔值；active/pending 读会话状态机。成熟度：beta（质量统计未接数据面）。

## 需求与字段映射
- adminapi.Presence 接口：Online(ctx,deviceID)(bool,error)。
- Overview/ListDevices 使用 s.online；presence 错误按离线。
- stack.BuildAdmin 注入 presence；cmd/admin 用 RedisBus 构造 signal.Presence；PG+Redis stack 传同一 presence。

## 能力链
- signal.Presence → adminapi.Service → Overview/ListDevices
- tests：presence false/true 覆盖设备表 true

## 当前证据
- A-08/后台：Overview/ListDevices 直接读 d.Online（绑定设备即在线），与 ER-112 权威租约不一致。

## 设计与不变量
- 在线状态唯一权威：presence；设备表字段只作开发兜底。
- presence 查询失败按离线，不放行。
- active/pending 来自 session.Service，不自行解释。
- 质量数据必须与客户端同一数据面来源（未完成）。
