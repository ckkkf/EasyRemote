# ER-503 通道映射：控制可靠有序 / 数据背压 / 视频不阻塞

## 目标与成熟度
在原生 QUIC 传输上落实协议通道语义：视频/音频走 datagram；控制走独立长驻 uni 流；数据走独立 bidi 流；控制不被视频/数据背压阻塞。成熟度：experimental（原生 QUIC 完成；浏览器 WebTransport 适配未实现）。

## 需求与字段映射
- Channel：Video/Audio datagram；Control/Data reliable。
- 控制流：单条 uni stream，首字节 channel=2，之后每帧 u32 len + payload。
- 数据流：单条 bidi stream，首字节 channel=3，读端由对端 accept_bi。
- 接收：后台 reader 任务 accept_uni/accept_bi，按长度分帧送入 mpsc。
- 背压：每通道队列上限 256，满返回 Backpressure。

## 能力链
- QuicTransport send_reliable/recv_reliable
- reader task 分帧 + stats
- tests：控制有序（视频灌包）、数据背压不阻塞控制、既有端到端

## 当前证据
- 旧实现每条可靠消息新开 uni stream，控制顺序无保证；Data 也走 uni，无 bidi。
- 无控制/数据隔离与背压测试。

## 设计与不变量
- 控制/数据各一条长驻流，互不共享队列。
- 控制帧顺序 = 发送顺序；视频丢包不影响控制流。
- 数据队列满返回 Backpressure，不无限排队。
- 单帧上限 16MB，超限断开读流；统计来自真实收发点。
