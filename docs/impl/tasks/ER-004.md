# ER-004 硬编码 / 空 catch / 固定 sleep / FFI 指针扫描规则

## 目标与成熟度
把四类“看起来完成、实际有债”的模式做成可自测的确定性扫描器，接入严格闸门；存量按规则+文件计数形成基线，只许减少不许新增。成熟度：disabled → beta（规则与自测可用；存量清零由后续卡逐项完成）。

## 需求与字段映射
N/A（工程规则，不改接口/协议）。

## 能力链
- 扫描器：`scripts/check-forbidden.mjs`（规则表 + 文件级分析 + JSON 基线）
- 自测：`scripts/tests/check-forbidden.test.mjs`（fixture 级正/负样本）
- 闸门：`scripts/gate.mjs` 的 forbidden 步骤（CI 同命令）
- 存量清单：`scripts/gate-baseline.json`

## 当前证据
- 旧扫描器只查 httpx 绕过与网关裸 map，且基线是“文件 计数”文本，无法表达多规则。
- A-15：`client/lib/pages/session_page.dart`、`device_list_page.dart` 硬编码 127.0.0.1/19000。
- A-16：`session_video_io.dart`、`host_service_io.dart` `toNativeUtf8` 未释放。
- 空 catch / 固定 sleep 散落在客户端与 Go 业务路径，缺少统一拦截。

## 设计与不变量
- 规则 id 稳定：`httpx-bypass`、`bare-map`、`hardcoded-endpoint`、`empty-catch`、`fixed-sleep`、`ffi-pointer-balance`。
- 每条规则声明适用范围（语言/目录），测试、example、stub、生成物不参与（避免把测试替身当生产）。
- 输出按 `rule:path -> count`；基线 JSON 只允许 count 下降；新增即退出 1。
- `--report` 只打印；`--update-baseline` 需人工批准（gate 参数直通）。
- FFI 规则用“toNativeUtf8 次数 > calloc.free 次数”判定不平衡，并允许同一文件多次分配一次释放循环（只报净差）。
- 硬编码规则不扫描注释以外的“示例 URL 文档字符串”？暂不区分注释，存量已入基线，新增即红，避免解释器复杂化。

## 先写的失败测试
- `TestHttpxBypassDetected`：Go 裸写响应被计入。
- `TestBareMapDetected`：网关 map[string]any 被计入。
- `TestHardcodedEndpointDetectedAndTestsExcluded`：client/lib 命中，client/test 不命中。
- `TestEmptyCatchDetected`：单行/多行空 catch 命中，有语句不命中。
- `TestFixedSleepDetected`：client/lib 的 Future.delayed 与 server/internal 的 time.Sleep 命中。
- `TestFfiPointerBalance`：2 分配 1 释放报 1，平衡报 0。
- `TestReportOnlyAndBaselineFormat`：JSON 基线可读写，报告模式不判红。
