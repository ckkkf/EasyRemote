# ER-502c 生产 host/ctrl 接入 P2P 协商

## 目标与成熟度
生产 host_stream 与 ctrl_session 在注册后使用同一套候选交换/打洞/ready，双方成功才切 P2P；被控状态上报 link。成熟度：experimental（代码接入；独立进程 P2P E2E 未自动化）。

## 需求与字段映射
- RelayClient.negotiate_p2p：prepare→await→punch→ready→activate，返回是否 P2P。
- HostStreamStats.link（p2p/relay）；FFI er_host_stream_status 暴露 link。
- Dart HostStatus.link。
- host_stream 在 begin 后协商；ctrl_session 两处 begin 后协商。

## 能力链
- host_stream/ctrl_session → RelayClient.negotiate_p2p
- send/recv 链路切换（ER-502b）
- status/FFI/Dart link 可观测
- tests：既有 E2E；未新增独立进程 P2P 断言

## 当前证据
- ER-502b 只在 pair 接入；生产独立进程仍全 Relay。

## 设计与不变量
- 双方顺序一致；失败保持 Relay，不影响会话。
- 协商在握手前完成；握手/加密逻辑不变。
- link 状态必须可观测；不得把 Relay 显示成 P2P。
- 生产 token 仍是 session 派生（临时），后续替换会话密钥。
