# ER-903g 时钟偏差（会话）

## 目标与成熟度
注入控制器/服务端时钟前跳与回退，验证 requested 超时、授权窗口与 ready 语义不误杀、不永久有效。成熟度：完成（单元时钟注入）。

## 需求与字段映射
- session.SetClock 注入；ConsentTimeout=30s、AuthWindow=12h。
- tests：TestClockBackwardDoesNotExpireConsent / TestClockForwardExpiresConsent / TestClockForwardExpiresAuthWindow。

## 验收断言 → 测试 → 结果
| 断言 | 测试 | 结果 |
|---|---|---|
| 回退 1h 不误判 consent/ready | TestClockBackwardDoesNotExpireConsent | PASS |
| 前跳 >30s consent 超时 | TestClockForwardExpiresConsent | PASS |
| 前跳 >12h ready 失败 | TestClockForwardExpiresAuthWindow | PASS |
