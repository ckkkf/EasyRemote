# ER-504b 手动重连（显式降级）

## 目标与成熟度
v1 不实现会话级自动重连；会话页提供显式“重连”入口，重新 attach 同一会话，并在文档/能力上保持 experimental。成熟度：降级方案（手动）。

## 需求与字段映射
- SessionPage 工具栏新增 reconnect（key=reconnect），点击：取消轮询 → SessionVideo.close → 重新 attach → 重启轮询。
- SessionVideo.close 清空 ffi session/image，允许同一实例再次 attach。
- 测试：TestManualReconnectReattaches（attach 调用两次）。

## 能力链
- UI 按钮 → _reconnectVideo → SessionVideo.attachRunner
- tests：attach 次数/attached=false 失败路径

## 当前证据
- 无自动重连状态机；断网后只能退出重进。
- 无手动重连入口。

## 设计与不变量
- 不伪装自动重连；5s/10s 阈值不承诺。
- 重连必须显式释放旧 image/session 再 attach。
- 失败保持明确错误，不显示已连接。
- 生产仍 experimental；发布说明需标注手动重连。
