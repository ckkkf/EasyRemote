# ADM-API-05c 配置分组/作用域 + 审计导出（缺口卡）

> 状态：**未开始**（缺口卡；由 ADM-UI-00b 复核登记）
> 来源：`docs/spec/pages.md` A12（行 258-260）、A13（行 264-266）、PRD §6.3.7（行 626-637）、§6.3.8（行 653）

## 缺什么

1. **配置分组**（画质 / 连接 / 限流 / 开关）与**平台/版本作用域**：当前配置项是扁平 key-value，没有 group 与 scope 字段。
2. **审计 CSV 导出**（按模块导出用户/设备/会话/风控，导出动作本身进审计）。

## 为什么不能现在做

- 分组/作用域会改变配置读取语义（同一 key 多作用域取值优先级），属于契约与存储变更，需要单独设计；
- CSV 导出需要流式响应 + 脱敏规则（手机号/设备码），不能用前端拼字符串代替。

## 建议拆分

- ADM-API-05c1：配置项 group/scope 字段 + 读取优先级 + 迁移。
- ADM-API-05c2：审计导出接口（CSV 流 + 审计记录 + 脱敏）。

## 进度（ADM-UI-00c 复核）

- 已完成：05c1（分组 + 平台作用域 + 读取优先级）、05c2（审计 CSV 导出，含脱敏与导出审计）。
- 仍缺：**版本作用域**（配置按客户端版本生效，需要版本维度与优先级规则）；用户/设备/会话模块的导出（当前只有用户与审计）。
