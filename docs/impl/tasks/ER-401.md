# ER-401 设备身份与会话令牌使用系统安全存储

## 目标与成熟度
桌面端账号令牌/设备令牌/设备身份写入系统安全存储；旧明文 session.json 一次性迁移并删除；注销擦除；安全存储不可用时 fail-closed。成熟度：beta（Web 仍 localStorage，威胁模型归 ER-902）。

## 需求与字段映射
- SecretStore：read/write/delete。
- SystemSecretStore：FlutterSecureStorage（Keychain/Credential Manager/libsecret）。
- key：easyremote.session.v1；value 为 StoredSession JSON。
- 旧文件：~/.easyremote/session.json（或 sessionFilePathOverride）。

## 能力链
- session_store_io：secure read/write/delete + legacy migration
- api.dart save/load/clearSession 不变（自动使用安全存储）
- tests：内存 SecretStore、临时旧文件
- flutter_test_config：测试注入内存实现（测试环境无平台通道）

## 当前证据
- 旧实现明文 JSON（600 权限）存 token/device_token；注销删除文件。
- 无平台安全存储抽象，无法测试失败路径。

## 设计与不变量
- 读取顺序：安全存储 → 旧明文迁移；安全存储不可用直接按未登录并删除旧明文，绝不回退。
- 保存失败必须上抛（不能显示登录成功但未持久化）。
- 注销先删安全存储，再删旧文件；安全存储删除失败上抛。
- 损坏 JSON 删除并要求重新登录。
- 测试环境使用内存实现；生产默认 SystemSecretStore。
