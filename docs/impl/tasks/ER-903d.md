## 目标与成熟度
独立 PG/Redis 容器上注入 kill/restart，观察网关行为与恢复；发现 /healthz 不反映依赖健康。成熟度：beta（本机容器）。

## 需求与字段映射
- scripts/chaos/db_redis_restart.sh：随机端口独立容器；stack PG+Redis；登录后探针。
- Redis kill/restart；PG kill/restart；探针 /healthz 与 /admin/v1/stats/overview。

| 场景 | 观察 | 结果 |
|---|---|---|
