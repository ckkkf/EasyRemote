# ER-411 生产配置一致性校验

## 目标与成熟度
生产启动必须校验数据库/Redis/密钥/公开端点/TLS/调试开关；缺任何一项或半配置直接失败；补 PG+Redis 生产 smoke。成熟度：beta。

## 需求与字段映射
- config.ValidateDeployment(getenv)：
  - 必需：DATABASE_URL、REDIS_URL、ER_SECRET、ER_PUBLIC_GATEWAY_URL、ER_PUBLIC_SIGNAL_URL、ER_PUBLIC_RELAY_ADDR。
  - 公开端点必须 https、非 localhost；relay 非 localhost；ER_PUBLIC_TLS=1。
  - 禁止 ER_ADMIN_TOTP_OFF 与开发 secret。
- cmd/gateway、cmd/admin、cmd/stack 启动即校验。

## 能力链
- 环境变量 → config.ValidateDeployment → cmd 启动失败/继续
- stack.NewPostgresWithRedis PG+Redis 组合
- tests：配置矩阵 + 双容器 smoke

## 当前证据
- 生产只校验 ER_SECRET/TOTP 开关；缺 Redis 时网关静默无通知（ER-111 已部分拒绝）、stack 仅有局部检查。
- 没有统一端点/半配置校验与 PG+Redis 组合启动测试。

## 设计与不变量
- 生产缺配置必须启动失败，不允许“半工作”。
- 端点必须显式、HTTPS、非 localhost；TLS 必须开启。
- 调试开关在生产直接失败（与 adminMFADisabled 双保险）。
- 开发/测试不受影响。
