# ER-811 登出撤销、token 存储与 CSP

## 目标与成熟度
登出调用服务端撤销会话；token/身份改存 sessionStorage；API 与 UI 加 CSP/安全头；测试覆盖旧 token 失效与 CSP。成熟度：beta（生产静态托管仍需下发 CSP 响应头）。

## 需求与字段映射
- api.logout POST /admin/v1/logout。
- App 登出先 api.logout，再清 token/identity；失败提示但本地仍清。
- getToken/setToken/getIdentity 用 sessionStorage。
- adminhttp securityHeaders：CSP default-src none/frame-ancestors none、nosniff、no-referrer。
- web-admin/index.html CSP meta。

## 能力链
- UI logout → adminhttp logout → adminsession.Revoke
- UI CSP meta / API CSP 头
- tests：TestLogoutRevokesTokenAndSecurityHeaders、TestAdminIndexHasRestrictiveCsp

## 验收断言 → 测试 → 结果
| 断言 | 测试 | 结果 |
|---|---|---|
| 登出后旧 token 失效 | TestLogoutRevokesTokenAndSecurityHeaders | PASS |
| API 带 CSP/nosniff | 同上 | PASS |
| UI CSP 存在且无 unsafe-eval | TestAdminIndexHasRestrictiveCsp | PASS |
| 严格闸门 | bash scripts/gate.sh | GATE: PASS |
