# ER-711e ACK 超时重发与重复块幂等

## 目标与成熟度
发送端保存最后未 ACK 块，超时重发；接收端重复块幂等；降低长链路 ACK 丢失导致传输卡死。成熟度：experimental（opt-in）。

## 需求与字段映射
- StreamSender.last_msg / retransmit()：in_flight 时返回最后块；ack 后清空。
- ctrl_session：300ms 未 ACK 重发。
- conductor.connect_device：200ms recv 超时重发。
- StreamReceiver：FileReceiver 重复块接受但不重复计数。

## 验收断言 → 测试 → 结果
| 断言 | 测试 | 结果 |
|---|---|---|
| 未 ACK 可重发同一块 | retransmit_until_ack | PASS |
