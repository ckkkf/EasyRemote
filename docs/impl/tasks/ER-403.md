# ER-403 验证码/临时密码 CSPRNG、周期、长度与锁定

## 目标与成熟度
设备验证码与临时密码使用 CSPRNG，符合 PRD 的长度/周期/锁定；移除 Rust 端时间+PID+LCG 生成密码。成熟度：beta（账号短信/邮箱固定码仅开发通道，生产必须注入 provider）。

## 需求与字段映射
- 设备码：9 位数字，crypto/rand，冲突重试。
- 一次性验证码：6 位数字，TTL 10 分钟，5 次错误锁定 30 分钟，校验即消费。
- 临时密码：6..16 位字母数字，服务端只存 HMAC 哈希，不消费。
- Rust host_password：8 位数字，getrandom CSPRNG；随机源失败返回空串（上层长度校验失败），绝不回退可预测值。

## 能力链
- device.Service RotateCode/VerifyCode/SetPassword
- store VerifyAndConsume 原子校验+消费+锁定
- conductor::ensure_host_password
- tests：格式/轮换/随机源/锁定/过期/重放/密码校验

## 当前证据
- 服务端已用 crypto/rand，TTL/锁定存在；缺显式轮换与随机源测试。
- Rust ensure_host_password 使用时间+PID+LCG，8 位密码可预测（安全红线）。

## 设计与不变量
- 所有凭证随机数必须 CSPRNG；禁止时间/PID/LCG。
- 轮换后旧码立即不可用；验证码一次性消费；并发由存储层原子保证。
- 5 次错误锁定；锁定期间不因正确码放行。
- 临时密码不轮换、不消费，服务端只存哈希。
