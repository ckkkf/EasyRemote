# ER-502a 候选交换编码与链路握手（部分）

## 目标与成熟度
为 P2P 集成提供可认证的候选交换消息（magic/token/session 校验，IPv4 列表编解码），供 pair/conductor 在 Relay 上交换候选。成熟度：experimental（编码/测试完成；会话编排仍未接线）。

## 需求与字段映射
- CANDIDATE_MSG_MAGIC=ERLINK1。
- 编码：magic(7)+token(16)+sidLen(u16)+sid+count(u8)+ (kind,u32 ip,u16 port)*。
- 解码校验：magic/token/session 不匹配或超 16 候选返回 None。

## 能力链
- p2p::encode_candidates/decode_candidates
- tests：roundtrip、错误 token/session
- 缺口：pair/conductor 未调用；无链路 ready 两阶段/切流

## 当前证据
- ER-502 只有本地打洞函数；候选无法跨进程交换。
- 无消息格式/认证/上限测试。

## 设计与不变量
- token/session 必须匹配，否则丢弃（防串会话/注入）。
- 候选数上限 16；只支持 IPv4。
- 编解码不分配超大 buffer。
