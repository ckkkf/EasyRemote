## 0. 阅读方式

每个页面给出五件事：**入口 → 布局要点 → 状态（加载/空/正常/错误）→ 交互 → 跳转**。
状态不全的页面不允许进入开发。

# 一、客户端页面

## C1. 启动页

| 项 | 内容 |
|---|---|
| 入口 | 应用启动 |
| 内容 | Logo + 版本号 + 加载指示 |
| 状态 | 检查更新中 / 检查登录态中 / 完成 |
| 跳转 | 未登录 → C2；已登录 → C3；强制升级 → C17 |

**异常**：更新检查失败不阻塞，直接进主流程。

## C2. 登录页

| 项 | 内容 |
|---|---|
| 入口 | C1 未登录 / C20 退出登录 |
| 布局 | 手机号输入 + 获取验证码 + 验证码输入 + 登录按钮 + 协议勾选 |
| 状态 | 正常 / 发送中 / 发送成功（60s 倒计时）/ 错误（100001、100009）/ 登录中 / 登录失败 |
| 交互 | 勾选「同意用户协议与隐私政策」后才可点登录；未勾选点击给出提示 |
| 跳转 | 成功 → C3 |

**异常分支**
- `100004` 尝试过多 → 锁定倒计时
- `100005` 账号封禁 → 展示申诉入口
- `100008` 短信失败 → 可重试

## C3. 首页（设备列表）

| 项 | 内容 |
|---|---|
| 入口 | 登录成功 / 会话结束返回 |
| 布局 | 顶部：账号头像 + 下拉菜单；主体：设备卡片网格；底部/次级：输入设备码、协助他人（V1） |
| 卡片内容 | 设备名、平台图标、在线状态点、设备码（可复制）、最后在线 |
| 状态 | 加载（骨架屏）/ 空（「还没有设备，在两台设备登录同一账号即可」）/ 正常 / 错误（拉取失败 + 重试） |
| 交互 | 点击卡片 → 直连（同账号）；长按 → 重命名 / 移除 / 查看详情；下拉刷新 |
| 跳转 | C4 / C5 / C6 / C12 / C13 / C14 |

**关键设计**：老用户 1 次点击进会话。**输入框不是首屏主体**（痛点 B 的产品判断，见 PRD §3.1）。

## C4. 输入设备码

| 项 | 内容 |
|---|---|
| 入口 | C3「输入设备码」 |
| 布局 | 9 位数字输入框（自动分段 3-3-3）+ 连接按钮 |
| 状态 | 正常 / 查询中 / 设备不存在（200001）/ 离线（200002）/ 设备忙（200008） |
| 交互 | 粘贴自动识别；输入满 9 位自动发起查询 |

## C5. 验证码输入

| 项 | 内容 |
|---|---|
| 入口 | C4 查询成功（跨账号） |
| 布局 | 6 位验证码输入 + 剩余锁定次数提示 |
| 状态 | 正常 / 错误（200003，显示剩余次数）/ 过期（200004）/ 锁定（200005） |
| 交互 | 输满自动提交 |

## C6. 等待对方授权

| 项 | 内容 |
|---|---|
| 入口 | C5 校验通过 |
| 布局 | 加载动画 + 「正在等待对方确认…」+ 取消按钮 |
| 状态 | 等待中（30s 倒计时）/ 超时（200007）/ 被拒（200006）/ 已同意 → 建连进度 |
| 建连进度 | 打洞中 → 打洞成功(P2P) / 切中继 → 密钥协商 → 首帧 |
| 跳转 | 成功 → C7；失败 → 错误页 C16 |

**设计要点**：建连阶段的每一步都要可见（「正在打洞」「已切换中继」），这是信任感的来源。

## C7. 会话中（核心页）

| 项 | 内容 |
|---|---|
| 布局 | 全屏远端画面 + 常驻工具栏 + 质量浮层 |
| 工具栏 | 画质▾ / 全屏 / 文件 / 剪贴板开关 / 声音（V1）/ 输入模式 / 更多⚙ |
| 质量浮层 | 右上角，显示 fps / 延迟 / 码率，可折叠为状态圆点（绿/黄/红） |
| 状态 | 正常 / 重连中（overlay + 倒计时）/ 对方暂停 / 隐私屏 / 只读（V2） |
| 交互 | 点击浮层 → C8；点击画质 → 档位选择器；右键远端 → 远端右键菜单（V1） |
| 跳转 | C8 / C9 / C10 / 断开回 C3 |

**关键设计**
- 工具栏**桌面常驻**，移动端手势唤出（PRD §5.4 的取舍）。
- 断线时**不销毁画面**，保留最后一帧 + 重连遮罩——比黑屏体验好得多。

## C8. 会话中 · 质量详情

| 项 | 内容 |
|---|---|
| 入口 | 点击质量浮层 |
| 布局 | 半屏面板：实时指标 + 链路信息 + 「网络诊断」按钮 |
| 指标 | fps、端到端延迟、码率、丢包、RTT、编码耗时、解码耗时、抖动缓冲 |
| 链路 | P2P / 中继、NAT 类型（双方）、当前档位 |
| 状态 | 正常 / 数据不足（刚连上） |

## C9. 会话中 · 网络诊断（差异化 D1）

| 项 | 内容 |
|---|---|
| 入口 | C8 底部按钮 |
| 布局 | 诊断进度（逐项打勾）+ 结论区（人话）+ 建议区 |
| 步骤 | 1 检查本地网络 → 2 探测 NAT 类型 → 3 尝试直连 → 4 测量带宽 → 5 汇总 |
| 结论示例 | 「当前使用中继转发（P2P 打洞失败）｜原因：你的网络为对称型 NAT｜影响：延迟 +12ms，码率上限 6Mbps｜建议：如在公司网络，可联系网管放行 UDP 443」 |
| 状态 | 诊断中（约 10s）/ 完成 / 失败（可重试） |

**这是产品差异化核心**，文案必须写成人话，不能甩 IP 和端口。

## C10. 文件传输

| 项 | 内容 |
|---|---|
| 入口 | 工具栏「文件」 |
| 布局 | 双栏（本地 / 远端）+ 顶部传输队列 |
| 队列项 | 文件名、方向、进度、速度、剩余时间、暂停/取消 |
| 状态 | 空 / 传输中 / 暂停 / 失败（500001–500009）/ 完成 |
| 交互 | 拖拽上传下载、右键菜单、多选、冲突弹窗（覆盖/跳过/重命名） |

## C11. 会话中 · 更多菜单

画质设置、显示器切换（V1）、发送组合键（Ctrl+Alt+Del 等）、开启水印（V1）、全屏模式、断开。

## C12. 设置 · 通用

语言、开机自启、最小化到托盘、更新检查、画质偏好。

## C13. 设置 · 安全（被控端本地）

| 项 | 默认 |
|---|---|
| 允许被远程控制（总开关） | 关 |
| 每次连接需确认 | 开 |
| 临时验证码轮换周期 | 10 分钟 |
| 隐私屏默认开启 | 关 |
| 剪贴板同步 | 开 |
| 文件传输 | 开 |
| 阻止会话期间系统睡眠（D2） | **开** |
| 会话水印 | 关（V1） |

**安全铁律提示条**：页面顶部常驻一行「这些设置只能在被控端本机修改，远程会话无法开启它们」。

## C14. 设置 · 关于

版本、检查更新、用户协议、隐私政策、开源许可、反馈。

## C15. 本机设备页（被控端）

| 项 | 内容 |
|---|---|
| 布局 | 大字号设备码（可复制）+ 临时验证码（倒计时）+ 被控开关 + 最近连接记录 |
| 状态 | 被控关闭 / 被控开启待连接 / 会话中（显示控制者） |
| 交互 | 复制设备码；查看最近 200 条连接记录 |

## C16. 错误页 / 空态

按错误码分段展示：标题（用户提示）+ 副文案（建议动作）+ 重试按钮 + 「查看诊断」入口。

## C17. 强制升级页

版本过低（100010）时展示，不可跳过，提供下载入口。

## C18. 授权弹窗（被控端）

| 项 | 内容 |
|---|---|
| 触发 | 有人请求连接 |
| 内容 | 控制者昵称、账号尾号、IP 归属地、「这不是我认识的人？」提示 |
| 按钮 | 接受 / 拒绝 / 拉黑该账号 |
| 状态 | 等待中（30s 倒计时）/ 已接受 / 已拒绝 |

## C19. 被控端悬浮条

会话期间常驻，显示「正在被 XXX 远程控制」+ 时长 + 一键断开。**不可被远程关闭**（安全红线）。

## C20. 账号菜单

切换账号、退出登录、注销账号。

# 二、管理后台页面

## A1. 登录

账号密码 + TOTP 二次验证（强制）。IP 白名单命中失败时提示。

## A2. 仪表盘

| 区块 | 内容 |
|---|---|
| 规模卡 | 在线设备、在线用户、进行中会话、24h 新增设备 |
| 质量卡 | 建连成功率、P2P 命中率、中继占比、延迟 P50/P95、帧率达成率 |
| 稳定性卡 | 会话异常中断率、崩溃率、重连成功率 |
| 趋势图 | 24h / 7d / 30d，可按平台、版本下钻 |

## A3. 用户列表

| 项 | 内容 |
|---|---|
| 列 | 账号 ID、昵称、手机号（脱敏）、注册时间、设备数、最近登录、状态 |
| 筛选 | 账号 ID / 手机号 / 昵称 / 状态 / 注册时间范围 |
| 操作 | 查看详情、封禁（填原因）、解封、踢下线、备注 |
| 导出 | CSV（导出动作进审计） |

## A4. 用户详情

基本信息、绑定设备列表、最近 20 次会话（含质量）、操作记录、备注。

## A5. 设备列表

| 列 | 设备码、设备名、归属账号、平台、系统版本、客户端版本、最后在线、NAT 类型 |
| 筛选 | 设备码 / 设备名 / 账号 / 平台 / 版本 / 在线状态 |
| 操作 | 详情、强制下线、解绑、标记风险 |

## A6. 设备详情（客服排查主入口）

设备信息 + **近 30 天质量曲线**（延迟/丢包/档位/是否走中继）+ 最近会话列表。
判断「是个案还是普遍问题」就看这一页。

## A7. 会话列表

| 列 | 会话 ID、主控设备、被控设备、开始时间、时长、平均延迟、链路（P2P/中继）、结束原因 |
| 筛选 | 时间范围、账号、设备、链路类型、是否异常结束 |
| 操作 | 详情、强制中断（填原因） |

## A8. 会话详情

质量曲线（每秒采样）、链路切换记录、错误码时间线、双方设备信息。

## A9. 强制中断确认弹窗

必填原因（下拉 + 自定义）+ 二次确认 + 明确提示「双方会在 3 秒内断开并收到通知」。

## A10. 风控中心（V1）

异常连接告警列表、黑名单管理（IP/设备码/账号，支持 CIDR 与有效期）、验证码爆破记录、举报工单。

## A11. 版本管理

版本列表（版本号/平台/状态/覆盖率）、灰度发布（5/20/50/100% 或白名单）、强制升级阈值、更新日志编辑。

## A12. 配置中心

配置项列表（key、当前值、默认值、平台/版本作用域、变更历史）、编辑、一键回滚。

**配置项分组**：画质 / 连接 / 限流 / 开关。

## A13. 审计日志

| 列 | 时间、操作人、角色、动作、对象、变更前后、IP、结果 |
| 筛选 | 时间范围、操作人、动作类型、对象 |
| 无删除、无编辑**，只可查询与导出 |

## A14. 管理员与角色

账号列表、角色分配、MFA 状态、禁用。

# 三、页面覆盖检查（DoD）

上线前逐项确认：

- [ ] 每个页面的四种状态（加载/空/正常/错误）都有设计稿
- [ ] 每个错误码都有对应展示位置（弹窗 / 页面 / 行内 / 仅日志）
- [ ] 所有网络请求都有 loading 与失败重试
- [ ] 所有写操作都有二次确认（后台）或撤销机会（客户端）
- [ ] 空态都有引导文案，不是空白页
- [ ] 断网时每个页面都不白屏
