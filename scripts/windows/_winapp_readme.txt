EasyRemote · Windows 主控端（远控 macOS）
=====================================

【这是什么】
一个 Windows 桌面程序：填设备码 + 验证码，就能看到并操作一台 macOS 的屏幕
（鼠标移动/点击/滚轮/键盘都会转发过去）。链路是端到端加密的（ed25519 + x25519）。

【怎么用】
1. 在 macOS 被控端启动 EasyRemote 被控程序（由管理员执行，会显示 9 位设备码 + 6 位验证码）。
2. 双击 EasyRemote.exe。
3. 在窗口里填：
     设备码：9 位数字（被控端屏幕上显示）
     验证码：6 位数字（10 分钟轮换一次）
   点「连接」。连上后中间区域就是 macOS 的实时画面。
4. 鼠标点进画面即可操作；「断开」结束会话。

【配置文件 er.conf】（可选，放在 exe 同目录）
   gateway=http://127.0.0.1:18090   # 网关地址（默认走本机隧道）
   relay=127.0.0.1:19000            # 中继地址
   phone=13700008102                # 主控端手机号（开发模式任意号，短信码固定 123456）
   device_code=                     # 留空则启动后手动输入
   captcha=                         # 同上
   auto_connect=0                   # 1 = 启动即自动连接（需要填好设备码/验证码）

【安装】
解压到任意目录即可，无需管理员权限、无需安装运行时（MSVC 运行库随系统）。

【已知限制】
- 画面约 1 帧/秒：macOS 侧是 OpenH264 软件编码（1080p 一帧约 400ms），
  要流畅需要接 VideoToolbox 硬件编码（后续版本）。
- 首次连接约 5 秒（等被控端确认 + 双向握手），属正常。
- 被控端需要「屏幕录制」和「辅助功能」两项 macOS 授权，缺一项会表现为
  黑屏或鼠标不动（不是本程序的 bug）。
